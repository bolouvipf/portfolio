# Portfolio — Pierre Florent BOLOUVI

Portfolio interactif de **Pierre Florent BOLOUVI**, étudiant en MI2 à l'ENS Natitingou (Bénin), développeur et fondateur de **HOUETOR**.

> Transformer des idées en produits technologiques.

## Contenu

- Explorateur de projets interactif : filtres par statut, recherche, fiches détail
- Projets : HOUETOR, Houetor Connect, JuriAgent, Hell Cousins, EasyHealth, HouetorTeach, H.hare, VibeWiki…
- Parcours, compétences (filtrage des projets par technologie), contact
- Thème clair/sombre, palette de navigation `Ctrl+K`, fond animé réactif

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou :

```bash
python -m http.server 8000
# http://localhost:8000
```
